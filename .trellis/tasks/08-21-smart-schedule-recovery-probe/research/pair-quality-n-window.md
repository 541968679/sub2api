# 方案陈述：双轨质量（账号 15m 不变 / 配对最近 N 条）

用户 2026-08-21 口述。本文只规范化，不写实现。

## 定义

- **账号质量 \(Q_a\)**：全站共享的账号级质量，所有用户、列表格子、硬关闭共用。
- **配对质量 \(Q_{a,u}\)**：仅用于智能调度 **账号×用户** 冷却判断。不写回 \(Q_a\)。
- **完成请求**：已有终态的一次调度（成功写入 usage，或计入错误口径的失败）。进行中的请求不是样本。
- **N**：该用户该平台策略上的冷却窗口长度。原「最少成功样本 / 最少 TTFT 样本」两字段改成这一个 N。两窗齐样都是 N。

## 轨 A — 账号质量（不变）

| 项 | 值 |
| --- | --- |
| 作用域 | `account_id`，全局一份 |
| 计算窗口 | 最近 15 分钟已完成请求 |
| 计算间隔 | 每 5 分钟 |
| 用途 | 账号质量格、快照、账号硬关闭。**不再作为智能调度冷却的输入** |

## 轨 B — 配对质量（冷却专用，本方案要改的）

| 项 | 值 |
| --- | --- |
| 作用域 | 仅 `(account_id, user_id)`。其他用户打同一账号不进这两扇窗（Q11）。 |
| 计算窗口 | 该配对最近 **N 条完成样本**（条数窗，不是 15 分钟） |
| 计算间隔 | 每完成一条就重算 \(Q_{a,u}\)（成功、失败都进窗） |
| 错误口径 | 与账号轨同一套：`schedule_use_failover_error_rate` 开则 Recovered/failover 计入失败；关则只计 terminal |
| 重置 | 该配对 **冷却结束、重新变为可调度** 时，窗口清空，从 0 再累计 |

### 首字窗口 \(W_{ttft}\)（已决）

N 对 **首字 / p50** 的含义是：该配对最近 **N 条「成功且有首字」** 的完成请求。

计入 \(W_{ttft}\) 当且仅当同时成立：

1. `(account_id, user_id)` 匹配；
2. 请求成功；
3. 存在首字时延（`true_first_token_ms` 或 `first_token_ms` 非空）。

**不计入** \(W_{ttft}\)：

- 失败（含是否按 failover 开关计错，都不进首字窗）；
- 同步等无首字的成功请求。

窗口是长度至多 N 的 FIFO。每入一条就重算 p50 = 窗内 N 条（或未满时不足 N 条）TTFT 的中位数。

**\(W_{ttft}\) 条数 `< N`：该配对不因首字门槛冷却。**

### 成功率窗口 \(W_{ok}\)（已决：与首字共用 N，成员不同）

- 长度同样是 N，FIFO。
- 计入：该配对已完成且应按错误口径入样的请求（成功，或失败且 failover 开关认定计入）。
- 不计入：count_tokens 等账号轨已排除的行；failover 关闭时的 Recovered 失败。
- 成功率 = \(W_{ok}\) 内成功数 / \(W_{ok}\) 条数。
- **\(W_{ok}.len < N\)：不因成功率门槛冷却。**

两窗共用配置里的同一个 N，但是两份队列：一条「成功且有首字」进 \(W_{ttft}\)；一条「计入口径的完成」进 \(W_{ok}\)。一条失败只进 \(W_{ok}\)；一条无首字的同步成功只进 \(W_{ok}\)；一条流式成功有首字则两窗都进。

or/and 仍按现网：未满的那一窗该指标不进入判断。`or` 时一窗已满且越界即可冷却；`and` 时两窗都满且都越界才冷却。

### 冷却判断（间隔仍是每条选号 + 每次入窗后）

设门槛仍为该用户平台策略上的 p50 上限 / 最低成功率 / or·and。

**解读（待你确认）：** 窗口条数 `< N` 时不判断、不写冷却（重新累计期间 fail-open）。条数 `= N` 后，每次入窗重算，再用门槛比；越界则 `HSETNX` 配对冷却。

选号时：若冷却 HASH 未到期 → 拒绝，不比 \(Q_{a,u}\)。否则可读最近一次算好的 \(Q_{a,u}\)（与「完成时已算」一致）。

冷却锁本身不变：墙钟 `cooldown_minutes`，质量变好不提前解。

### 豁免期 / 可调度（Q12–Q13）

界面改名为「豁免期」（原「已恢复」）。API / 代码仍为 `resumed`（Q14）。`selectable` = 「可调度」。

| 动作 | 冷却 | 两窗 | 判断 |
| --- | --- | --- | --- |
| 豁免期 | 清除 | 进入时清零；**期内新完成入窗** | 时间豁免内完全不判断（`u:` 15m + `w:` 至 30m）。期满后再比；已满 N 可立刻冷却 |
| 可调度 | 清除 | 清零，重新攒 N | 无时间豁免；未满 N 不冷却 |
| 冷却自动到期 | 过期 | 同可调度 | 无时间豁免 |

不保留冷却前窗口。点可调度不再写 15 分钟 `w:`。

## 刻意不变

- 账号 15m / 5min 计算。
- 配对冷却 HASH、paused、池成员、pair cap。
- 客户端协议。本阶段不做考察期夹并发。

## 与旧字段的张力

策略里仍有 `quality_min_success_samples` / `quality_min_ttft_samples`（默认 20/10）。若齐样仍用它们，而 N=5，则成功率永远判不了。规范化默认：**配对冷却的齐样条件就是 N**；这两个最少样本字段不再约束轨 B。
